# Ce qui m'attend

Les données : `accompagnement/` du poste (sans lui, skill `preparer-le-poste`). La personne du poste et ses rôles : les consignes du poste.

1. **Les fiches.** Lire l'en-tête de chaque `accompagnement/Entreprises/*/fiche.md`.
2. **Ce qui attend.** Les fiches dont le rôle qui attend est un rôle de ce poste ; pour un référent, celles dont il est le référent. Les classer par date du prochain geste, les retards en premier.
3. **Les doublons.** Deux fiches pour la même entreprise, sous des noms voisins : les signaler au propriétaire.
4. **Le rendu.** Une liste courte : l'entreprise, l'étape, le prochain geste, sa date.
