# Transmettre une demande

Le parcours : `${CLAUDE_PLUGIN_ROOT}/methode/accompagnement.md`, étape 11. Les données : `accompagnement/` du poste (sans lui, skill `preparer-le-poste`). La personne du poste et ses rôles : les consignes du poste.

1. **La demande.** Écrire `accompagnement/Entreprises/<entreprise>/demandes/<AAAA-MM-JJ>.md` : ce que l'entreprise veut, dans ses mots ; pourquoi ; ce qu'elle fera quand ce sera fait ; ce qui presse. Une demande par fichier.
2. **La fiche.** Étape 11 ; le rôle qui attend : `developpeur` ; le prochain geste ; une ligne d'historique.
3. **La suite.** La demande revient au référent avec sa conception, puis suit l'étape 5 : skill `ecrire-une-offre`.
