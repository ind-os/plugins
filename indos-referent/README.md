# indos-referent

Le plugin `indos-referent` tient le rôle de référent d'AVQN : la méthode d'accompagnement d'une entreprise, du premier contact à la fin de la relation, avec ses modèles et ses skills. Il exige `indos-poste`, le poste et ses entreprises.

## Ce qu'il porte

| Dossier | Ce qu'il tient |
| --- | --- |
| `methode/accompagnement.md` | La méthode : les rôles, le parcours d'une entreprise, l'audit gratuit, les données, les documents envoyés |
| `modeles/` | La fiche, le plan de séance, le rapport d'audit, l'offre, le devis |
| `contrats/referent.md` | Le contrat de référent |
| `emetteur.json` | Qui émet les documents : AVQN |
| `skills/` | Un geste du parcours par skill |
| `consignes.md` | Les consignes du rôle, que l'IA reçoit au début de chaque session sur le poste |

Un membre de l'équipe propose un changement de la méthode par une pull request ; le propriétaire la fusionne.
